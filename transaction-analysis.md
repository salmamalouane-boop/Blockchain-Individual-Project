# Bitcoin TestNet4 Transaction Analysis

## 1. Introduction
This document presents the analysis of a Bitcoin transaction performed on the Bitcoin TestNet4 network.

## 2. Wallets
- Sender: Wallet_A
- Receiver: Wallet_B

## 3. Faucet Transaction
Wallet_A received 330,808 sats from the TestNet4 Faucet.

## 4. Transaction Details
- Total amount transferred: 330,000 sats
- Transaction fee: 808 sats

## 5. Transaction Analysis

The transaction includes:

- Input: The funds used to create the transaction.
- Output: The amount sent to Wallet_B.
- Change: The remaining amount returned to Wallet_A.
- Fee: The network fee paid to process the transaction.

## 6. Verification
The transaction was verified using mempool.space on the Bitcoin TestNet4 network.

## 7. Conclusion
This practical exercise provided hands-on experience with Bitcoin transactions and helped understand transaction inputs, outputs, change, and fees.
