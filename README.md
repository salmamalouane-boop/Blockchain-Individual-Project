# Analyse d'une transaction Bitcoin sur TestNet4

## 1. Introduction

Ce projet porte sur l'analyse d'une transaction Bitcoin
réalisée sur le réseau TestNet4 à l'aide de Wasabi Wallet.

L'objectif est de comprendre le fonctionnement d'une
transaction Bitcoin à travers une expérience pratique.

## 2. Objectifs du projet

- Comprendre le fonctionnement des transactions Bitcoin.
- Identifier les Inputs et les Outputs.
- Analyser les frais de transaction.
- Comprendre le mécanisme UTXO.
- Observer le processus de validation des transactions.

## 3. Méthodologie

L'étude s'appuie sur une expérience pratique réalisée
sur le réseau Bitcoin TestNet4, en utilisant deux
wallets distinctes et un explorateur blockchain.
